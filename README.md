## 🌟 Overview & Core Value Proposition

Students and early-career developers are frequently told to build a GitHub portfolio, but they rarely know **what a recruiter notices in the first 30 seconds**, whether their repositories look abandoned, which projects should be highlighted, or what concrete steps to take first.

**GitHub Roast & Rescue** bridges this gap by combining:
1. **GitHub REST API Live Data** — Profile, repositories, README checks, topic tags, commit recency.
2. **Deterministic Portfolio Scoring (100 Pts)** — Consistent, explainable rules across 6 core evaluation categories.
3. **Tasteful AI Roast** — Clever, developer-insider humor roasting the *profile* presentation, not the person.
4. **Recruiter 30-Second View** — Instant hiring manager impressions, strengths, and red flags.
5. **Prioritized Rescue Plan** — Concrete triage (*Fix First*, *Fix Next*, *Nice to Have*) with simulated score gains and an interactive 7-day action roadmap.

## 📐 Deterministic 100-Point Scoring Model

| Category | Weight | Sub-Criteria Checked |
| :--- | :---: | :--- |
| **Profile Quality** | **15 pts** | Bio presence, custom profile README (`user/user`), display name, external links (portfolio/blog), contactability. |
| **Repository Quality** | **25 pts** | Description ratio (10 pts), topic tags ratio (5 pts), community stars & forks (5 pts), professional naming (5 pts). |
| **Documentation** | **20 pts** | Repository README ratio (12 pts), top project README quality (4 pts), open source licenses (4 pts). |
| **Activity & Cadence** | **15 pts** | Recency of last push (6 pts), maintained repos in last 6 months (5 pts), account tenure consistency (4 pts). |
| **Project Diversity** | **10 pts** | Distinct programming stacks/languages (7 pts), original work vs fork ratio (3 pts). |
| **Recruiter Readiness** | **15 pts** | Top 3 showcase presentation (6 pts), recruiter contact avenues (4 pts), clutter vs curation ratio (5 pts). |
| **Total** | **100 pts** | Strict, explainable score (A: 85+, B: 70–84, C: 50–69, D: <50). |

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 19, Vite 8, Tailwind CSS v4, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express, Axios, Dotenv, CORS
- **APIs**:
  - **GitHub REST API v3**: Users, Repos, README endpoints, Rate-limit caching

## ⚡ Quick Start

### 1. Prerequisites
- **Node.js**: v18+ (tested on Node v24)
- **npm**

### 2. Installation
Clone the repository and install all dependencies:
```bash
# Install root, backend, and frontend packages
npm run install:all
```

### 3. Environment Variables (Optional)
Create a `.env` file in the root or `server/` directory:
```env
PORT=5000

# Optional: Higher rate limit (5,000 req/hr vs 60 req/hr)
# GITHUB_TOKEN=ghp_your_personal_access_token

# Optional: Google Gemini API Key for live generative AI
# GEMINI_API_KEY=AIzaSy_your_gemini_api_key
```
> *Note: If no API keys are provided, the app runs completely out of the box using public GitHub endpoints and the built-in dynamic roast engine!*

### 4. Running the Application
```bash
# Build the client bundle
npm run build

# Start the full-stack server
npm start
```
Visit **http://localhost:5000** in your browser!

For live front-end development with hot reloading:
```bash
# Terminal 1: Backend API
npm run server

# Terminal 2: Vite React Client
npm run client
```

## 🎯 Hackathon 60-Second Demo Script

1. **The Hook (10s)**: "Every student is told to make a GitHub, but nobody tells them what a recruiter actually sees. In 30 seconds, recruiters decide whether to interview or skip."
2. **The Test (15s)**: Enter a real username (or click `@octocat` / `@shadcn`). Watch the personality-driven loading steps: *🔍 Inspecting repositories... 🧐 Checking README quality... 👀 Thinking like a recruiter... 🔥 Preparing the roast...*
3. **The Reveal (15s)**:
   - Point to the **Deterministic Score** (e.g. 65/100) and explain that the score is rule-based and explainable.
   - Read the **Tasteful AI Roast** citing their real repository count and habits.
   - Show the **Recruiter 30-Second View** (Strengths vs Friction points).
4. **The Rescue & ROI (20s)**:
   - Open the **Prioritized Rescue Plan** showing *Fix First* with ready-to-copy README templates.
   - Toggle the **Score Simulator** to show how tackling these fixes raises their score to 88/100 (+23 points).
   - Show the **7-Day Action Plan** and 1-click **Export PDF**.
5. **Close**: "GitHub Roast & Rescue: Don't just tell developers their GitHub needs work. Tell them why—and exactly how to fix it."
